    58→    58→   - .btn-hover { transition: all .18s ease; }
    59→    59→   - .btn-hover:hover { transform: translateY(-1px); }
    60→    60→   - .btn-hover:active { transform: translateY(0); }

    64→    64→   - Cards use solid bg-elevated with hairline borders, NOT glassmorphism everywhere
    65→    65→   - Glassmorphism reserved ONLY for: top header (mobile) and sidebar (desktop)
